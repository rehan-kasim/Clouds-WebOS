## Made using
* Vite
* Javascript
* Tailwind
### Dependencies
* Node 26.x
* Modern Browser 
* And internet
### Excuting
* Just open ```https://clouds-os.vercel.app/```
* Or to host this localy follow the instruction below
### Installing
* Download the Zip or
*  ```git clone https://github.com/rehan-kasim/Clouds-WebOS.git``` and ```cd Clouds-WebOS```
### Executing program
* Step 1 : ```npm install```
* Step 2 : ```npm run build```
* Step 3 : ```npm run dev```
